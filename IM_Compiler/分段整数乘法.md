一、算法 1：分段整数乘法（规范化伪代码）

> **Algorithm 1: Segmented Integer Multiplication (IR-Level)**  
> _Executed cooperatively by_ **NT threads** _of the_ **gid-th thread group**

### 输入

- `A, B`: 两个 N 位大整数
- `Ns`: 分段位长（architecture-dependent hyper-parameter）
- `NT`: 并行线程数
- `segA, segB`: A, B 的 Ns 位分段表示
- `UNIT_MUL(a, b)`: 并行计算两个 Ns 位整数的乘法

### 输出

- `C = A × B`，以 Ns 位分段形式存储在 `segC`

---

### 伪代码（结构化、代码生成友好）

```
// Step 0: 分段
divide A, B, C into Ns-bit segments
segA[0 .. (N/Ns)-1]
segB[0 .. (N/Ns)-1]
segC[0 .. (2N/Ns)-1]

// Step 1: 初始化
carry    ← 0
arrHigh  ← array[Ns] initialized to 0
arrLow   ← array[Ns] initialized to 0

//-------------------------------------------
// Phase 1: 计算低位部分 (n = 0 .. N/Ns - 1)
//-------------------------------------------
for n = 0 to (N / Ns) - 1 do
    // 滑动窗口初始化
    carry    ← 0
    arrLow   ← arrHigh
    arrHigh  ← 0

    for i = 0 to n do
        A′ ← segA[gid][i]
        B′ ← segB[gid][n - i]

        (arrHigh′, arrLow′) ← UNIT_MUL(A′, B′)

        // 局部累加（避免RMW冲突）
        (carry, arrHigh, arrLow) ←
            (carry, arrHigh, arrLow) + (0, arrHigh′, arrLow′)
    end for

    segC[gid][n] ← arrLow
end for

//-------------------------------------------
// Phase 2: 计算高位部分 (n = N/Ns .. 2N/Ns - 1)
//-------------------------------------------
for n = (N / Ns) to (2N / Ns) - 1 do
    carry    ← 0
    arrLow   ← arrHigh
    arrHigh  ← 0

    for i = n - (N / Ns) + 1 to (N / Ns) do
        A′ ← segA[gid][i]
        B′ ← segB[gid][n - i]

        (arrHigh′, arrLow′) ← UNIT_MUL(A′, B′)

        (carry, arrHigh, arrLow) ←
            (carry, arrHigh, arrLow) + (0, arrHigh′, arrLow′)
    end for

    segC[gid][n] ← arrLow
end for
```

## 二、算法核心思想分析

### 1️⃣ 分段整数乘法（Segmented Multiplication）

- 每个 N 位整数被划分为 `N / Ns` 个 `Ns` 位段
- 整数乘法转化为 **分段卷积（convolution）**
- 满足：

C\[n]=∑_i+j=nsegA\[i]×segB\[j]C\[n] = \sum\_{i+j=n} segA\[i] \times segB\[j]

这与经典长整数乘法（schoolbook）一致，但粒度变为 **Ns 位段**

---

### 2️⃣ 两阶段遍历顺序（避免进位冲突）

整个乘法按对角线顺序遍历：

- **Phase 1（低位）**：`0 ≤ n < N/Ns`
- **Phase 2（高位）**：`N/Ns ≤ n < 2N/Ns`

✅ **关键优势：**

- 对每个输出段 `segC[n]`，只写一次
- 避免全局数组的 **Read–Modify–Write**
- 进位在寄存器阵列 `arrHigh / arrLow` 中本地处理

---

### 3️⃣ UNIT_MUL 的角色（并行接口的唯一入口）

(arrHigh′, arrLow′) = UNIT_MUL(A′, B′)

- 输入：两个 Ns 位整数
- 输出：2Ns 位结果（高、低两部分）
- **由 NT 个线程协作完成**
- 是 **唯一与 GPU 架构强相关的组件**
